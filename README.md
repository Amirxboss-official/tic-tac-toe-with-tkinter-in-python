# Tic-Tac-Toe with Tkinter in Python

Hello! 👋

A simple Tic-Tac-Toe game built with **Python** and **Tkinter**.  
This project includes a graphical user interface, winner detection, and game restart functionality.

## Features

- 🎮 Two-player gameplay
- 🏆 Winner detection
- 🤝 Draw detection
- 🔄 Restart game button
- 🖥️ Simple Tkinter GUI

## Technologies

- Python 3
- Tkinter

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/tic-tac-toe-with-tkinter-in-python.git
```
2. Open the project folder:

```bash
cd tic-tac-toe-with-tkinter-in-python
```

3. Run the game:
```bash
python main.py
```
